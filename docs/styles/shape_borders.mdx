Phluts provides various shape border classes to define the shape of widgets like buttons, cards, and containers.

## Available Shape Borders

| Class                         | Description                                      |
|-------------------------------|--------------------------------------------------|
| `PhlutsRoundedRectangleBorder`  | Rectangle with rounded corners.                  |
| `PhlutsCircleBorder`            | Circular shape.                                  |
| `PhlutsBeveledRectangleBorder`  | Rectangle with beveled (cut) corners.            |
| `PhlutsContinuousRectangleBorder`| Rectangle with smooth continuous corners.       |

## PhlutsRoundedRectangleBorder

### Properties

| Property     | Type                    | Description                              |
|--------------|-------------------------|------------------------------------------|
| borderRadius | `Map<String, dynamic>?` | Border radius for rounded corners.       |
| side         | `Map<String, dynamic>?` | Border side properties.                  |

### Example

<CodeGroup>
```dart Dart
PhlutsElevatedButton(
  style: PhlutsButtonStyle(
    shape: PhlutsRoundedRectangleBorder(
      borderRadius: PhlutsBorderRadius.all(12.0),
      side: PhlutsBorderSide(
        color: PhlutsColors.blue,
        width: 2.0,
      ),
    ),
  ),
  child: PhlutsText(data: 'Rounded Button'),
)
```

## PhlutsCircleBorder

### Properties

| Property     | Type                    | Description                              |
|--------------|-------------------------|------------------------------------------|
| eccentricity | `double?`               | Eccentricity of the circle (0.0 to 1.0). |
| side         | `Map<String, dynamic>?` | Border side properties.                  |

### Example

<CodeGroup>
```dart Dart
PhlutsElevatedButton(
  style: PhlutsButtonStyle(
    shape: PhlutsCircleBorder(
      side: PhlutsBorderSide(
        color: PhlutsColors.green,
        width: 2.0,
      ),
    ),
  ),
  child: PhlutsIcon(icon: 'add'),
)
```

</CodeGroup>

## PhlutsBeveledRectangleBorder

### Properties

| Property     | Type                    | Description                              |
|--------------|-------------------------|------------------------------------------|
| borderRadius | `Map<String, dynamic>?` | Border radius for beveled corners.       |
| side         | `Map<String, dynamic>?` | Border side properties.                  |

### Example

<CodeGroup>
```dart Dart

  shape: PhlutsBeveledRectangleBorder(
    borderRadius: PhlutsBorderRadius.all(16.0),
  ),

    padding: PhlutsEdgeInsets.all(16.0),
    child: PhlutsText(data: 'Beveled Card'),
  ),
)
```

## With Container

<CodeGroup>
```dart Dart

  decoration: PhlutsBoxDecoration(
    color: PhlutsColors.blue,
    borderRadius: PhlutsBorderRadius.only(
      topLeft: 20.0,
      topRight: 20.0,
      bottomLeft: 0.0,
```

## Button Shapes Comparison

<CodeGroup>
```dart Dart
PhlutsColumn(
  children: [
    // Rounded Rectangle
    PhlutsElevatedButton(
      style: PhlutsButtonStyle(
        shape: PhlutsRoundedRectangleBorder(
          borderRadius: PhlutsBorderRadius.all(8.0),
        ),
      ),
      child: PhlutsText(data: 'Rounded'),
    ),
    PhlutsSizedBox(height: 8.0),
    // Stadium (pill shape)
    PhlutsElevatedButton(
      style: PhlutsButtonStyle(
        shape: PhlutsRoundedRectangleBorder(
          borderRadius: PhlutsBorderRadius.all(50.0),
        ),
      ),
      child: PhlutsText(data: 'Stadium'),
    ),
    PhlutsSizedBox(height: 8.0),
    // Circle
    PhlutsElevatedButton(
      style: PhlutsButtonStyle(
        shape: PhlutsCircleBorder(),
        minimumSize: PhlutsSize(width: 56.0, height: 56.0),
      ),
      child: PhlutsIcon(icon: 'favorite'),
    ),
  ],
)
```
