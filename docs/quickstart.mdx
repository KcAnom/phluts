## Prerequisites

- Flutter SDK: `>=3.35.0`
- Dart SDK: `>=3.0.0 <4.0.0`

## Create a Flutter app (if needed)

If you don't already have a Flutter app, create one and navigate into it:

```bash
flutter create phluts_demo
cd phluts_demo
```

## Sign up

The first thing you'll need to do is sign up for a Phluts account. It's free and only takes a few seconds.

To create an account, head over to our Console and sign in with Google: [console.phluts.dev](https://console.phluts.dev).

## Install Phluts CLI

The Phluts CLI helps you scaffold projects, manage screens, and deploy to Phluts Cloud.

<Tabs>
<Tab title="macOS / Linux">
Open your terminal and run:

```bash
curl -fsSL https://raw.githubusercontent.com/PhlutsDev/install/main/install.sh | bash
```

</Tab>
<Tab title="Windows">
Open PowerShell and run:
```bash
irm https://raw.githubusercontent.com/PhlutsDev/install/main/install.ps1 | iex
```

</Tab>
</Tabs>

Verify installation:

```bash
phluts --version
```

## Login to Phluts

Run the login command. This opens your browser to authenticate with Google.

```bash
phluts login
```

## Initialize Phluts in your project

From your Flutter app directory, initialize Phluts:

```bash
phluts init
```
You'll be prompted to select an option. You can either choose to use an existing project or create a new one.

Phluts will now initialize the project and you'll see a message saying


`phluts init` will add the following to your project:
- `phluts/hello_world.dart` – A Hello World example widget. All your Phluts widgets live in the `phluts` folder.
- Adds `phluts` to your `pubspec.yaml`.
- Creates `default_phluts_options.dart`, which defines your `PhlutsOptions` (e.g., project name and ID).


## Build Phluts widgets

Head over to `phluts/hello_world.dart` and build the widget. Use the `@PhlutsScreen` annotation to mark the widget as a screen.

```dart
import 'package:phluts/phluts_core.dart';

@PhlutsScreen(screenName: 'hello_world')
PhlutsWidget helloWorld() {
  return PhlutsScaffold(
    body: PhlutsCenter(child: PhlutsText(data: 'Hello, world!')),
  );
}
```

Phluts follows Flutter's conventions for building widgets. For example, to use Flutter's `Scaffold`, use the `PhlutsScaffold` widget.

## Deploy Phluts widgets

Now that we have our widget built, we can deploy it to Phluts Cloud.

```bash
phluts deploy
```

This finds all widgets in the `phluts` folder, builds them, and deploys them to Phluts Cloud.

## Initialize Phluts

Now that your project is set up, open `main.dart` and initialize Phluts.

```dart
import 'package:phluts_demo/default_phluts_options.dart';
import 'package:flutter/material.dart';
import 'package:phluts/phluts.dart';

void main() async {
  await Phluts.initialize(options: defaultPhlutsOptions);
  runApp(const MyApp());
}
```

Now that Phluts is initialized, our app is ready to be dynamic and server-driven.

We can now render our `hello_world` screen using the `phluts` widget.

```dart
Phluts(routeName: 'hello_world'),
```

Here is the full example:


```dart
import 'package:example_app/default_phluts_options.dart';
import 'package:flutter/material.dart';
import 'package:phluts/phluts.dart';

void main() async {
  await Phluts.initialize(options: defaultPhlutsOptions);

  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Flutter Demo',
      theme: ThemeData(
        colorScheme: ColorScheme.fromSeed(seedColor: Colors.deepPurple),
      ),
      home: const Phluts(routeName: 'hello_world'),
    );
  }
}
```
