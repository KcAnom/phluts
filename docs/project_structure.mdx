This guide explains the overall structure of a Phluts project. It covers where the UI is defined, how parsers are organized, and how themes and routes fit together.

## Basic Structure

```
├─ flutter_project/
├── lib/
│   ├── app/                        # Feature-specific code (optional)
│   ├── default_phluts_options.dart   # Default PhlutsOptions for Phluts configuration
│   └── main.dart                   # Entry point for phluts initialize
├── phluts/
│   └── hello_world.dart            # Phluts widgets
├── pubspec.lock
└── pubspec.yaml
```

## Key Files

### default_phluts_options.dart

Contains the `PhlutsOptions` configuration for your project, including project name and ID.

```dart
import 'package:phluts/phluts_core.dart';

PhlutsOptions get defaultPhlutsOptions => PhlutsOptions(
  name: 'your-project-name',
  projectId: 'your-project-id',
  description: 'Optional project description',
);
```

### main.dart

Entry point for the Flutter app where Phluts is initialized. Custom parsers are registered here:

```dart
import 'package:flutter/material.dart';
import 'package:phluts/phluts.dart';
import 'default_phluts_options.dart';

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Phluts.initialize(
    options: defaultPhlutsOptions,
    parsers: [],       // Custom widget parsers
    actionParsers: [], // Custom action parsers
  );
  runApp(const MyApp());
}
```

### phluts/ folder

Contains your Phluts widget definitions written in Dart. Each file can contain one or more `@PhlutsScreen` annotated functions.

## Extended Structure

For larger projects, here's a recommended structure:

```
├─ flutter_project/
├── lib/
│   ├── app/
│   │   ├── parsers/                  # Custom widget and action parsers
│   │   │   ├── widgets/
│   │   │   │   └── custom_chart_parser.dart
│   │   │   └── actions/
│   │   │       └── analytics_action_parser.dart
│   │   └── theme/
│   │       └── app_theme.dart        # Theme configuration
│   ├── default_phluts_options.dart
│   └── main.dart
├── phluts/
│   ├── screens/                      # Organized by feature
│   │   ├── home/
│   │   │   └── home_screen.dart
│   │   ├── profile/
│   │   │   └── profile_screen.dart
│   │   └── settings/
│   │       └── settings_screen.dart
│   ├── components/                   # Reusable UI components
│   │   ├── header.dart
│   │   └── footer.dart
│   └── .build/                       # Generated JSON (auto-created)
│       ├── home_screen.json
│       ├── profile_screen.json
│       └── settings_screen.json
├── pubspec.lock
└── pubspec.yaml
```

## Build Output

When you run `phluts build` or `phluts deploy`, the Dart files are converted to JSON and placed in `phluts/.build/`:

```
phluts/
├── home_screen.dart          # Your Dart source
├── app_theme.dart            # A @PhlutsThemeRef definition
└── .build/
    ├── screens/
    │   └── home_screen.json  # Generated JSON output
    └── themes/
        └── app_theme.json
```

<Note>
The `.build` folder is automatically created and should typically be added to `.gitignore` since it's generated from your Dart source files.
</Note>

## Custom Parsers

Custom widget and action parsers extend Phluts's capabilities. Place them in a dedicated folder and register them in `Phluts.initialize`:

```dart
// lib/app/parsers/widgets/custom_chart_parser.dart
import 'package:phluts_framework/phluts_framework.dart';

class CustomChartParser extends PhlutsParser<CustomChart> {
  @override
  String get type => 'customChart';

  @override
  CustomChart getModel(Map<String, dynamic> json) {
    return CustomChart.fromJson(json);
  }

  @override
  Widget parse(BuildContext context, CustomChart model) {
    return MyChartWidget(data: model.data);
  }
}
```

```dart
// lib/main.dart
await Phluts.initialize(
  options: defaultPhlutsOptions,
  parsers: [
    CustomChartParser(),
  ],
  actionParsers: [
    AnalyticsActionParser(),
  ],
);
```

## Theme Configuration

Themes can be configured through Phluts Cloud or locally via `PhlutsApp`:

```dart
class MyApp extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return PhlutsApp(
      title: 'My App',
      theme: PhlutsAppTheme(name: 'light_theme'),
      darkTheme: PhlutsAppTheme(name: 'dark_theme'),
      themeMode: ThemeMode.system,
      homeBuilder: (context) => Phluts(routeName: 'home_screen'),
    );
  }
}
```

You can also use JSON-based themes:

```dart
PhlutsApp(
  theme: PhlutsAppTheme.json(payload: myThemeJson),
  // ...
)
```

## Multiple Screens Organization

For apps with many screens, organize by feature or route:

```
phluts/
├── auth/
│   ├── login_screen.dart
│   ├── signup_screen.dart
│   └── forgot_password_screen.dart
├── dashboard/
│   ├── home_screen.dart
│   └── stats_screen.dart
└── settings/
    ├── settings_screen.dart
    └── profile_screen.dart
```

Each file uses the `@PhlutsScreen` annotation:

```dart
@PhlutsScreen(screenName: 'login')
PhlutsWidget loginScreen() {
  return PhlutsScaffold(
    body: PhlutsCenter(
      child: PhlutsText(data: 'Login'),
    ),
  );
}
```
