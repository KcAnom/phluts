Theming is an essential part of any application, ensuring a consistent look and feel across the entire app. Phluts offers flexible theming options that allow you to fetch themes from Phluts Cloud (recommended), load them over the network, or parse them from JSON.

## Overview

Phluts theming works similarly to Flutter's built-in theming system. You define themes using `PhlutsTheme` objects and apply them to your application using `PhlutsApp`. The framework supports multiple ways to load themes:

1. **Cloud Themes (Recommended)** - Fetch themes from Phluts Cloud by name
2. **Network Themes** - Load themes over HTTP using `PhlutsNetworkRequest`
3. **JSON Themes** - Parse themes from JSON data

## Using PhlutsApp with Themes

To use themes in your Phluts application, replace `MaterialApp` with `PhlutsApp` and pass your theme using the `PhlutsAppTheme` wrapper:

```dart
import 'package:flutter/material.dart';
import 'package:phluts/phluts.dart';

void main() async {
  await Phluts.initialize();
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return PhlutsApp(
      title: 'My App',
      theme: PhlutsAppTheme(name: "light_theme"),  // Cloud theme (recommended)
      darkTheme: PhlutsAppTheme(name: "dark_theme"),  // Cloud theme (recommended)
      homeBuilder: (context) => const HomeScreen(),
    );
  }
}
```

## Theme Sources

### 1. Cloud Themes (Recommended)

Fetch themes from Phluts Cloud by name. This is the recommended approach as it allows themes to be managed server-side and updated without app updates. Themes are cached locally for offline access and performance.

#### Workflow: Generate and Deploy Themes

To use Cloud themes, you first need to:

1. **Define your themes** in your `phluts/` directory using `@PhlutsThemeRef` annotation
2. **Generate JSON** from your DSL themes using the Phluts CLI
3. **Deploy to Phluts Cloud** using `phluts deploy`

Here's the complete workflow:

**Step 1: Define your theme** in `phluts/app_theme.dart`:

```dart
import 'package:phluts/phluts_core.dart';

@PhlutsThemeRef(name: "movie_app_dark")
PhlutsTheme get darkTheme => _buildTheme(
  brightness: PhlutsBrightness.dark,
  colorScheme: PhlutsColorScheme(
    brightness: PhlutsBrightness.dark,
    primary: '#95E183',
    // ... other properties
  ),
);
```

**Step 2: Generate and deploy** using the CLI:

```bash
phluts deploy
```

This command will:
- Build your project
- Process all `@PhlutsScreen` annotated screens and `@PhlutsThemeRef` annotated themes
- Generate JSON files for each screen and theme
- Upload all generated files to Phluts Cloud

Example output:
```
[INFO] Building project before deployment...
[INFO] Found 4 @PhlutsScreen annotated function(s)
[SUCCESS] ✓ Generated screen: onboarding_screen.json
[SUCCESS] ✓ Generated screen: home_screen.json
[SUCCESS] ✓ Generated screen: detail_screen.json
[INFO] Found 1 @PhlutsThemeRef definition(s) in phluts\app_theme.dart
[SUCCESS] ✓ Generated theme: movie_app_dark.json
[SUCCESS] Build completed successfully!
[INFO] Deploying screens/themes to cloud...
[SUCCESS] Uploaded screen: onboarding_screen.json
[SUCCESS] Uploaded screen: home_screen.json
[SUCCESS] Uploaded screen: detail_screen.json
[SUCCESS] Uploaded theme: movie_app_dark.json
[SUCCESS] Deployment completed successfully!
```

**Step 3: Use in your app**:

```dart
PhlutsApp(
  theme: PhlutsAppTheme(name: "movie_app_light"),
  darkTheme: PhlutsAppTheme(name: "movie_app_dark"),
  // ...
)
```

The `PhlutsAppTheme` wrapper automatically fetches the theme from Phluts Cloud using the provided name. Themes are cached intelligently to minimize network requests.

> You can also use DSL themes directly by passing a `PhlutsTheme` object to `PhlutsAppTheme.dsl(theme: myTheme)`. When using themes directly, the `@PhlutsThemeRef` annotation is not needed. The annotation is only required when you want to deploy themes to Phluts Cloud using `phluts deploy`.

### 2. Network Themes

Load themes over HTTP using a `PhlutsNetworkRequest`. This allows you to fetch themes from any API endpoint:

```dart
PhlutsApp(
  theme: PhlutsAppTheme.network(
    context: context,
    request: PhlutsNetworkRequest(
      url: 'https://api.example.com/themes/light',
      method: Method.get,
    ),
  ),
  // ...
)
```

### 3. JSON Themes

Parse themes directly from JSON data. Useful when themes are stored locally or received from other sources:

```dart
final themeJson = {
  "brightness": "dark",
  "colorScheme": {
    "brightness": "dark",
    "primary": "#95E183",
    "onPrimary": "#050608",
    // ... other color scheme properties
  },
  "textTheme": {
    // ... text theme properties
  }
};

PhlutsApp(
  theme: PhlutsAppTheme.json(payload: themeJson),
  // ...
)
```

## Theme Structure

A `PhlutsTheme` consists of several components:

### Color Scheme

The color scheme defines the primary colors used throughout your app:

```dart
PhlutsColorScheme(
  brightness: PhlutsBrightness.dark,
  primary: '#95E183',
  onPrimary: '#050608',
  secondary: '#95E183',
  onSecondary: '#FFFFFF',
  surface: '#050608',
  onSurface: '#FFFFFF',
  onSurfaceVariant: '#65FFFFFF',
  error: '#FF6565',
  onError: '#050608',
  outline: '#08FFFFFF',
)
```

### Text Theme

Define typography styles for different text elements:

```dart
PhlutsTextTheme(
  displayLarge: PhlutsCustomTextStyle(
    fontSize: 48,
    fontWeight: PhlutsFontWeight.w700,
    height: 1.1,
  ),
  headlineLarge: PhlutsCustomTextStyle(
    fontSize: 30,
    fontWeight: PhlutsFontWeight.w700,
    height: 1.3,
  ),
  bodyLarge: PhlutsCustomTextStyle(
    fontSize: 18,
    fontWeight: PhlutsFontWeight.w400,
    height: 1.5,
  ),
  // ... other text styles
)
```

### Button Themes

Customize button appearances:

```dart
// Filled button theme
PhlutsButtonStyle(
  minimumSize: PhlutsSize(120, 40),
  textStyle: PhlutsCustomTextStyle(
    fontSize: 16,
    fontWeight: PhlutsFontWeight.w500,
  ),
  padding: PhlutsEdgeInsets.only(left: 10, right: 10, top: 8, bottom: 8),
  shape: PhlutsRoundedRectangleBorder(borderRadius: PhlutsBorderRadius.all(8)),
)

// Outlined button theme
PhlutsButtonStyle(
  minimumSize: PhlutsSize(120, 40),
  side: PhlutsBorderSide(color: '#95E183', width: 1.0),
  shape: PhlutsRoundedRectangleBorder(borderRadius: PhlutsBorderRadius.all(8)),
)
```

### Floating Action Button Theme

Use `floatingActionButtonTheme` to customize colors, elevation, shape, icon sizing, and layout constraints for floating action buttons:

```dart
PhlutsFloatingActionButtonThemeData(
  backgroundColor: '#95E183',
  foregroundColor: '#050608',
  elevation: 6,
  shape: PhlutsRoundedRectangleBorder(borderRadius: PhlutsBorderRadius.all(16)),
  sizeConstraints: PhlutsBoxConstraints(minWidth: 56, minHeight: 56),
)
```

```json
{
  "floatingActionButtonTheme": {
    "backgroundColor": "#95E183",
    "foregroundColor": "#050608",
    "elevation": 6,
    "shape": {
      "type": "roundedRectangleBorder",
      "borderRadius": 16
    },
    "sizeConstraints": {
      "minWidth": 56,
      "minHeight": 56
    }
  }
}
```
