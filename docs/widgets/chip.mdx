The Phluts Chip allows you to build a Flutter Chip widget using JSON.
To know more about the Chip widget in Flutter, refer to the [official documentation](https://api.flutter.dev/flutter/material/Chip-class.html).

## Properties

| Property                   | Type                           | Description                                                                                    |
|----------------------------|--------------------------------|------------------------------------------------------------------------------------------------|
| avatar                     | `PhlutsWidget`                   | The widget to display prior to the chip's label.                                               |
| label                      | `PhlutsWidget`                   | The primary content of the chip.                                                               |
| labelStyle                 | `PhlutsTextStyle`                | The style to use for the label.                                                                |
| labelPadding               | `PhlutsEdgeInsets`               | The padding around the label.                                                                  |
| deleteIcon                 | `PhlutsWidget`                   | The widget to display as the chip's delete icon.                                               |
| onDeleted                  | `PhlutsAction`                   | The callback that is called when the delete icon is tapped.                                    |
| deleteIconColor            | `PhlutsColor`                    | The color of the delete icon.                                                                  |
| deleteButtonTooltipMessage | `String`                       | The message to display in the tooltip for the delete icon.                                     |
| side                       | `PhlutsBorderSide`               | The border to display around the chip.                                                         |
| shape                      | `PhlutsRoundedRectangleBorder`   | The shape of the chip's border.                                                                |
| clipBehavior               | `PhlutsClip`                     | The clip behavior of the chip. Defaults to `Clip.none`.                                        |
| autofocus                  | `bool`                         | Whether this chip should focus itself if nothing else is already focused. Defaults to `false`. |
| color                      | `PhlutsColor`                    | The color of the chip.                                                                         |
| backgroundColor            | `PhlutsColor`                    | The background color of the chip.                                                              |
| padding                    | `PhlutsEdgeInsets`               | The padding around the chip.                                                                   |
| visualDensity              | `PhlutsVisualDensity`            | The visual density of the chip.                                                                |
| materialTapTargetSize      | `PhlutsMaterialTapTargetSize`    | Configures the minimum size of the tap target.                                                 |
| elevation                  | `double`                       | The elevation of the chip.                                                                     |
| shadowColor                | `PhlutsColor`                    | The color of the chip's shadow.                                                                |
| surfaceTintColor           | `PhlutsColor`                    | The color of the chip's surface tint.                                                          |
| iconTheme                  | `PhlutsIconThemeData`            | The theme for icons in the chip.                                                               |
| avatarBoxConstraints       | `PhlutsBoxConstraints`           | The constraints for the avatar.                                                                |
| deleteIconBoxConstraints   | `PhlutsBoxConstraints`           | The constraints for the delete icon.                                                           |
