The Phluts Column allows you to build a Flutter column widget using JSON.
To know more about the column widget in Flutter, refer to the [official documentation](https://api.flutter.dev/flutter/widgets/Column-class.html).

## Properties

| Property           | Type                       | Description                                                                                      |
|--------------------|----------------------------|--------------------------------------------------------------------------------------------------|
| mainAxisAlignment  | `PhlutsMainAxisAlignment`    | How the children should be placed along the main axis. Defaults to `MainAxisAlignment.start`.    |
| crossAxisAlignment | `PhlutsCrossAxisAlignment`   | How the children should be placed along the cross axis. Defaults to `CrossAxisAlignment.center`. |
| mainAxisSize       | `PhlutsMainAxisSize`         | How much space should be occupied in the main axis. Defaults to `MainAxisSize.max`.              |
| textDirection      | `PhlutsTextDirection`        | The text direction to use for resolving alignment.                                               |
| verticalDirection  | `PhlutsVerticalDirection`    | The vertical direction to use for laying out children. Defaults to `VerticalDirection.down`.     |
| textBaseline       | `PhlutsTextBaseline`         | The baseline to use for aligning text.                                                           |
| spacing            | `double`                   | The spacing between children. Defaults to `0`.                                                   |
| children           | `List<PhlutsWidget>`         | The list of widgets to display inside the column. Defaults to an empty list.                     |

  mainAxisSize: PhlutsMainAxisSize.min,
  textDirection: PhlutsTextDirection.ltr,
  verticalDirection: PhlutsVerticalDirection.up,
  spacing: 10,
  children: [
    PhlutsText(data: 'Hello, World!'),

      height: 100,
      color: PhlutsColors.red,
    ),
  ],
)
