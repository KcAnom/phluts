The Phluts Colored Box allows you to build a Flutter colored box widget using JSON.
To know more about the colored box widget in Flutter, refer to the [official documentation](https://api.flutter.dev/flutter/widgets/ColoredBox-class.html).

## Properties

| Property | Type                    | Description                                      |
|----------|-------------------------|--------------------------------------------------|
| color    | `PhlutsColor`             | The color to paint the background of the box.    |
| child    | `PhlutsWidget`            | The widget to display inside the colored box.    |
