## Available Commands

| Command          | Description                        | Requires Auth |
| ---------------- | ---------------------------------- | ------------- |
| `login`          | Authenticate with Google OAuth     | No            |
| `logout`         | Clear stored authentication tokens | No            |
| `status`         | Show authentication status         | No            |
| `init`           | Initialize Phluts in project         | Yes           |
| `build`          | Convert Dart widgets to JSON       | No            |
| `deploy`         | Build and deploy to Phluts Cloud     | Yes           |
| `project list`   | List all cloud projects            | Yes           |
| `project create` | Create new cloud project           | Yes           |

## Authentication

Before using most CLI commands, you'll need to authenticate with Phluts Cloud.

### Login

This opens your browser for OAuth authentication. Your credentials are securely stored locally.

```bash
phluts login
```

### Check Status

```bash
phluts status
```

### Logout

```bash
phluts logout
```

## Initialize Phluts

Use this to set up Phluts in an existing Flutter/Dart project. It links your local app to a Phluts Cloud project and scaffolds required files.

```bash
phluts init
```

#### What it does

- Creates `phluts/` folder for Phluts DSL widgets
- Adds `lib/default_phluts_options.dart` with your `PhlutsOptions` (e.g., `projectId`)
- Updates `pubspec.yaml` with `phluts` and related dependencies
- Optionally links to an existing Phluts Cloud project

#### Generated files

```bash
|- Flutter project
├── lib/
│   ├── default_phluts_options.dart
│   └── main.dart
├── phluts/
│   └── phluts_widget.dart
└── pubspec.yaml
```

### Convert Dart to JSON

Build all widgets in current project:

```bash
phluts build
```

Build specific project directory:

```bash
phluts build --project /path/to/project
```

Build with validation (enabled by default):

```bash
phluts build --validate
```

Build with verbose output:

```bash
phluts build --verbose
```

#### Build Options

| Option          | Description                | Default           |
| --------------- | -------------------------- | ----------------- |
| `-p, --project` | Project directory path     | Current directory |
| `--validate`    | Validate generated JSON    | `true`            |
| `-v, --verbose` | Show detailed build output | `false`           |

The build command converts Phluts widget definitions from the `phluts/` folder into JSON format in the `build/` folder.

### Deploy to Phluts Cloud

Build and deploy to Phluts Cloud:

```bash
phluts deploy
```

Deploy specific project directory:

```bash
phluts deploy --project /path/to/project
```

Skip build and deploy existing files:

```bash
phluts deploy --skip-build
```

Deploy with verbose output:

```bash
phluts deploy --verbose
```

### Deployment Options

| Option          | Description                     | Default           |
| --------------- | ------------------------------- | ----------------- |
| `-p, --project` | Project directory path          | Current directory |
| `--skip-build`  | Skip building before deployment | `false`           |
| `-v, --verbose` | Show detailed deployment output | `false`           |

<Note>
  By default, `phluts deploy` automatically runs `phluts build` before deploying. Use `--skip-build` to deploy existing build files without rebuilding.
</Note>

### List Projects

List all your Phluts Cloud projects:

```bash
phluts project list
```

Output as JSON format:

```bash
phluts project list --json
```

The list command shows:

- Project name and ID
- Project description
- Created and updated timestamps

### Create New Project

```bash
phluts project create --name "My App" --description "My SDUI app"
```

Short form:

```bash
phluts project create -n "My App" -d "My SDUI app"
```

After creating a project, run `phluts init` to initialize it locally.

### Typical Workflow

1. Authenticate with Phluts Cloud (one-time):

```bash
phluts login
```

2. List available projects:

```bash
phluts project list
```

3. Initialize a project in your Flutter/Dart app:

```bash
cd your-flutter-project
phluts init
```

4. Create your widget definitions in the `phluts/` folder, then deploy:

```bash
phluts deploy
```
