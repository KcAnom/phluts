# Phluts Core

[![pub package](https://img.shields.io/pub/v/phluts_core.svg?label=phluts_core&color=blue)](https://pub.dev/packages/phluts_core)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)

A pure Dart package that provides the core functionalities and common interfaces for the [Phluts](https://pub.dev/packages/phluts) SDUI framework.

This package serves as the foundation for building server-driven UIs with Phluts by defining core models, functionalities, and common interfaces that Phluts packages depend upon.
