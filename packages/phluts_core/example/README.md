# Example

A pure Dart package that provides the core functionalities and common interfaces for the [Phluts](https://pub.dev/packages/phluts).

This package serves as the foundation for building server-driven UIs with Phluts by defining core models, functionalities, and common interfaces that phluts package depend upon.

For example please refer to [Phluts](https://pub.dev/packages/phluts).
