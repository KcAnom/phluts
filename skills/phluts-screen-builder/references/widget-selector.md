# Widget Selector

## Layout-First Mapping

- Page shell: `PhlutsScaffold`
- Vertical composition: `PhlutsColumn`
- Horizontal composition: `PhlutsRow`
- Scrollable content: `PhlutsListView` or `PhlutsSingleChildScrollView`
- Section spacing: `PhlutsPadding` and `PhlutsSizedBox`

## Interaction Mapping

- Primary button CTA: `PhlutsFilledButton` or `PhlutsElevatedButton`
- Icon action: `PhlutsIconButton`
- Form group: `PhlutsForm` + `PhlutsTextFormField`
- Conditional UI: `PhlutsConditional`

## Data Mapping

- Remote content list: `PhlutsDynamicView`
- Loading state: `PhlutsCircularProgressIndicator`
- Empty state: `PhlutsCenter` + `PhlutsText`
